오늘 기록

설정 · 시리 단축어 만드는 법
Apps Script 웹앱 URL
  1. 구글 시트 새로 만들기 → 확장 프로그램 → Apps Script
  2. Code.gs 내용을 통째로 붙여넣고 저장
  3. 배포 → 새 배포 → 유형: 웹 앱 → 실행: 나 / 액세스: 모든 사용자 → 배포
  4. 나온 /exec URL을 위 칸에 저장 (폰마다 한 번씩)
아이폰 시리 단축어
  1. 단축어 앱 → + → 이름 "분유 기록"
  2. 동작 추가: 입력 요청 → 유형 숫자, 질문 "몇 ml?"
  3. 동작 추가: URL 콘텐츠 가져오기 → URL은 위 /exec 주소, 방법 POST, 요청 본문 "양식"
  4. 양식 필드 추가: type = 분유, amount = (입력 요청 결과 변수)
  5. "시리야, 분유 기록" → "120" 하면 끝
아이폰 육아일기 단축어 (말하면 구글 문서에 저장)
  1. Apps Script 코드를 최신 Code.gs로 바꾼 뒤, 편집기에서 testDiary 함수를 한 번 실행해 권한 승인 (드라이브에 "육아일기" 문서가 자동 생성됨)
  2. 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포 (주소는 그대로)
  3. 단축어 앱 → + → 이름 "오늘 육아일기"
  4. 동작 추가: 받아쓰기 텍스트 → 언어 한국어, 듣기 중지 "일시 정지 후"
  5. 동작 추가: URL 콘텐츠 가져오기 → 위 /exec 주소, 방법 POST, 요청 본문 "양식", 필드 type = 일기, note = (받아쓴 텍스트 변수)
  6. "시리야, 오늘 육아일기" → 말하면 문서에 날짜별로 이어 적힘
삼성폰: 크롬 메뉴 → 홈 화면에 추가. 위 버튼으로 두 번 터치에 기록됩니다.
